# Third-party material

Bundled fonts, all under the SIL Open Font License 1.1 (full texts in
`assets/fonts/OFL-*.txt`), downloaded from the google/fonts repository:

| File | Font |
| --- | --- |
| `assets/fonts/Rubik.ttf` | Rubik (variable; LÖVE renders its default Light instance) |
| `assets/fonts/LilitaOne-Regular.ttf` | Lilita One |
| `assets/fonts/Silkscreen-Regular.ttf` | Silkscreen |

No other third-party code or art is included. The JSON encoder/decoder
(`lib/json.lua`), the sound synthesis, every shader and all drawing code were
written for this project. The game logic is a port of the author's own web game.
The only code of another studio's game that was consulted: none.
